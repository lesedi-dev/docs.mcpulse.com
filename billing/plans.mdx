<Note>
  **No payment processor is connected.** These are the shapes the screen renders, not something anything enforces today. Every account is on Free, nothing is metered against a limit, and no card is taken.

## The plan grid never flickers

It reads constants and local state, so it renders immediately rather than showing a loading placeholder. Anything with nothing to wait for must not look like it is waiting.

## What "16 metrics" means

The full set, on every plan:

Counted live — calls per tool, calls per day, which client, crashes, tool errors, bad arguments, empty answers, speed, result size, sessions, cost per session.

Computed nightly — retries, first-call success, tool pairs.

From the startup payload — schema size, dead tools.

See [The overview](/metrics/overview).
